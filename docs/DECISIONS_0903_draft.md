# DECISIONS · 2026-09-03 초안

## D-AI-29 · 시뮬 보조학습의 **성과 게이트**를 결과 보기 전에 확정한다

작성자: 김준태(트랙B) · 2026-09-03 · 관련 이슈 S15P21A103-65 · D-AI-18 보강

**배경**
D-AI-18 은 "시뮬을 보조로 **쓸 수 있는가**"를 붕괴율로 판정한다. 그건 자격 심사다.
여기서 정하는 것은 다른 질문이다 — **"쓴 결과 무엇이 나아졌는가."**
이 값을 결과 보기 전에 못 박지 않으면, 나중에 어떤 수치가 나와도 사후 합리화로 읽힌다.

**결정 — 두 기준 중 하나를 넘으면 "시뮬 보조학습이 유효하다"고 기록한다 (OR)**

| | 기준 | 값 |
|---|---|---|
| G1 | 같은 시연 수에서 롤아웃 성공률 향상 | **+20%p 이상** |
| G2 | 같은 성공률에 필요한 실시연 수 감소 | **40% 이상** |

기준값은 김준태(트랙B)가 정했다. 어시스턴트 제안(+10%p / 30%)보다 높다.

**측정 프로토콜 (L37 반영)**

- 두 팔(arm)을 **같은 시점에 함께** 측정한다
  - 대조군: 시연 N편만 학습
  - 실험군: 시뮬 사전학습 + 같은 시연 N편 파인튜닝
- **N ∈ {10, 20, 30, 50}** — G2 의 40% 감소는 `50 → 30` 비교가 정본이다
- 각 셀: **학습 3회 × 평가 3회**, 롤아웃 n=100, 합산 900편으로 보고
  - 평가 3회는 L37(같은 ckpt 재평가 범위 4%p) 때문에 필수다. 학습 반복만으로는 부족하다
- 모든 셀이 **같은 평가 시드 블록**을 본다
- 판정은 합산 Wilson 95% 구간으로 한다. 구간이 겹치면 "판정 불가"이지 "효과 없음"이 아니다

**G1 의 기준선은 절대값이 아니라 동시 측정값이다**
+20%p 는 "그 실험에서 같이 측정한 무시뮬 팔" 대비다. 오늘의 9.3% 를 고정 기준으로 쓰지 않는다.
데이터 결함이 고쳐져 기준선이 오르면 실험군도 같이 올라야 한다 — 그래야 공정하다.

**알고 넘어가는 것**
현재 기준선이 9.3% 이므로 G1 을 통과하면 실험군은 약 29% 가 되고, 이는 배포 게이트(20%)를
넘는다. 즉 **G1 통과 = "시뮬이 이 태스크를 게이트 위로 올렸다"** 와 거의 같은 말이다.
의도된 것으로 본다. 성과가 명확해지는 대신 기준이 높다.

**언제 측정할 수 있나 (지금은 불가)**
1. 평가 비결정성 원인 확인 (L37) — 프로토콜로 흡수했으나 원인은 미확정
2. 정책이 게이트를 통과할 것 — D-AI-18 전제(조건 A ≥ 20%)가 아직 미충족
3. 실시연 데이터 — 앱 변환기 없음, hand-eye·시간동기화 미계측
   → **그때까지는 시뮬 도메인 A/B 를 실물 대리로 써서 같은 계측기로 예행한다.**
     프록시 수치와 실물 수치를 **따로** 기록하고, 프록시를 실물 근거로 인용하지 않는다

**되돌릴 조건**
- 실시연 수집 비용이 예상보다 낮아 "시연 수 절감"이 제품 가치가 아니게 되면 G2 의 의미가 줄어든다
- VLA(SmolVLA 등)로 전환하면 기준선이 **실물 사전학습 위**가 된다. 그때 G1/G2 는
  "VLA 사전학습에 시뮬을 더해 얼마를 더 얻는가"로 다시 읽어야 하며, 값의 재검토가 필요하다

**왜 이 두 기준인가**
G2 가 제품 가치와 같은 축이다. 타겟이 다품종 소량생산이라 제품이 자주 바뀌고, 바뀔 때마다
시연을 많이 할 수 없다. 필요한 시연 수를 줄이는 것이 곧 티칭 교체 비용을 줄이는 것이다
(RESEARCH_business_case_0902 §3-A). G1 은 그것이 성능 손해 없이 이뤄졌는지를 지킨다.

**다른 트랙 영향**
데이터 계약 불변. 트랙 A 확인 불필요. 다만 실시연 N편 단위 실험이므로
**수집 프로토콜이 단계식(20 → 검증 → 100)과 충돌하지 않는지** 수집 착수 전에 맞춰야 한다.

## D-AI-29 개정 1차 — 평가 조건 홀드아웃 · 대조군 정의 · 통과 의미

개정 제안: **신현우(MW/PM)** · 2026-09-03 · 수용: 김준태(트랙B) · 원안 작성: 김준태

### ① 평가 조건은 사전학습에서 제외한다

사전학습이 평가에 쓰는 조건을 덮으면 ③의 기여가 부풀어 오른다. 같은 분포에서 뽑은
다른 시드는 "안 본 위치"이지만 **"안 본 조건"이 아니다** — 물체·조명·카메라가 같다.

두 종류를 **따로** 보고한다. 하나로 합치면 어느 쪽 능력인지 알 수 없다.

| 홀드아웃 | 무엇을 재나 | 방식 |
|---|---|---|
| **H1 보간** | 학습 분포 안의 안 본 위치 | 도달 가능 xy 격자를 무작위 분할, 사전학습은 학습 몫만 사용 |
| **H2 외삽** | 학습 분포 밖 | 외곽 링(학습 반경 밖)에서만 평가 |

- 물체 **위치·자세** 홀드아웃은 씬 수정 없이 지금 가능하다 (수집 시 xy 를 분할 샘플링)
- 물체 **종류·크기** 홀드아웃은 MJCF 에 변종을 넣어야 한다 → [ROS] 이슈 63 범위. 이번 회차에서 제외하고 그 사실을 병기한다
- 구현 필요: 수집·평가에 xy 영역 제한 인자. **미구현**

### ② 대조군 불변식 — "같은 모델 · 같은 실데이터 · 시뮬만 뺀 것"

| | 실험군 | 대조군 |
|---|---|---|
| BCNet 유지 시 | 시뮬 사전학습 → 실시연 N편 | **BCNet, 실시연 N편만** |
| SmolVLA 채택 시 | 시뮬 사전학습 → 실시연 N편 | **SmolVLA, 실시연 N편만 파인튜닝** |

**scratch 와 비교하지 않는다.** 그러면 모델 자체의 사전학습 효과가 시뮬 공으로 잡힌다.
SmolVLA 는 실물 SO-100 데이터로 이미 사전학습돼 있으므로, 그 경우 ③의 주장은
**"실물 사전학습 위에 시뮬을 더해 얼마를 더 얻는가"** 로만 읽어야 한다.

**⚠️ 미결 — 김준태 판단 필요.** 대조군이 SmolVLA(실데이터 파인튜닝)면 바가 크게 올라가고
G1 +20%p 는 통과 가능성이 낮아진다. 선택지 둘:
  (a) +20%p 를 그대로 둔다 — 통과하면 매우 강한 결과, 실패 확률 높음
  (b) VLA 대조군 경우에만 별도 값을 **지금** 정한다 — 결과 보기 전이므로 정당하다
어느 쪽이든 **결과를 본 뒤에는 못 바꾼다.** 지금 정해야 한다.

### ③ 게이트 통과의 의미 = "실물 시도 자격"

G1/G2 통과는 **"검증 완료"가 아니다.** 시뮬 내부 결과는 실제 sim2real 갭의 **하한**이다
(D-AI-18 한계). 통과가 뜻하는 것은 하나다 — **실물에서 시도해볼 자격을 얻었다.**

문서·발표·레지스트리에서 이 문구를 쓴다:

> "시뮬 게이트 통과 = 실물 시도 자격. 실물 성능은 실물 롤아웃 n=100 이 판정한다."

배포 게이트(`ROLLOUT_GATE 0.20`)도 같다. 시뮬에서 20% 를 넘은 정책은
**배포 가능이 아니라 실물 평가 대상**이다. 레지스트리 문구 점검 필요.
