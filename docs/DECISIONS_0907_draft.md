## D-AI-30 · 조건 비교의 표준 블록을 **학습 5회**로 올린다

작성자: 김준태(트랙B) · 2026-09-07 · 관련 이슈 S15P21A103-34, S15P21A103-35
합의: 트랙 A ☐ / 트랙 B ☐

**배경**

`contract/skills.py` 의 `GATE_MIN_RUNS = 3` 으로 지금까지 모든 조건을 비교했고,
합산 이항 구간(n=300)으로 "겹친다 / 갈라진다"를 판정했다. 그 합산이 틀렸다.
롤아웃끼리 정책을 공유하고, 3회 실행이 평가 시드 블록까지 공유한다. 독립 300 이 아니다.

**실행 수준으로 보면 3회는 구조적으로 부족하다** 🟢

3 vs 3 의 순열검정에서 가능한 배치는 C(6,3) = 20 가지이므로 **최소 단측 p 는
1/20 = 0.05** 다. 즉 어떤 3회 실험도 경계선을 넘을 수 없다.
실제로 v4(0, 0, 0) vs v5(2, 12, 14) — 지금까지 가장 큰 효과 — 가 정확히 p = 0.05 다.

5회면 C(10,5) = 252 → 최소 단측 p 는 0.004 다.

**결정**

| 목적 | 실행 수 | 근거 |
|---|---|---|
| "학습이 망가지지 않았나" 확인 | **3회 유지** | 총체적 고장 검출에는 충분하다 |
| **조건 A vs 조건 B 비교** | **5회** | 실행 수준 검정이 경계선을 벗어나는 최소값 |
| 배포 게이트 판정 | 5회 + n≥100 | 위와 같음 |

평가 시드 블록은 3000~3099 로 **유지**한다 (모든 조건이 같은 물체 배치를 본다).
비교는 같은 시드의 성공/실패 차이를 쓰는 **paired** 로 하고, 구간은 학습 실행을
군집으로 보는 부트스트랩으로 낸다.

**이것은 게이트 완화가 아니다**

`ROLLOUT_GATE = 0.20` 은 건드리지 않는다. 게이트를 옮기는 것은 사후 합리화이고
n 을 올리는 것은 정밀도 개선이다. 이 결정은 후자다.

**비용** 🟢

학습 1회 1332초(V100 1장, 44.4초/epoch × 30). 5회 = 111분.
GPU 10장이고 PCIe 라 GPU당 독립 잡이 맞으므로 **5장에 뿌리면 벽시계 22분**이다.
3회에서 5회로 가는 비용은 실질적으로 0 이다.

**되돌릴 조건**

- 실행 편차(L40, 현재 12%p)가 5%p 이하로 줄면 3회로 되돌릴 수 있다
- 5회에서도 판정이 안 되면 게이트를 옮기지 말고 **7회 또는 평가 n 을 올린다**

**파급**

- `contract/skills.py` `GATE_MIN_RUNS` — 상수 하나. 코드 변경 필요
- 이미 3회로 기록된 v2·v3·v4·v5·v6 판정은 **"경계선"으로 재표기**한다.
  소급 폐기는 하지 않는다 (기록에 없는 과거를 만들지 않는다)
- 트랙 A 의 도메인 랜덤화 붕괴율(D-AI-18)도 같은 문제를 갖는다 — **확인 필요**

## D-AI-31 · 조건 비교 실행은 **커밋된 트리에서만** 한다

작성자: 김준태(트랙B) · 2026-09-07 · 관련 이슈 S15P21A103-34
합의: 트랙 A ☐ / 트랙 B ☐

**배경** 🟢

`EXP_LOG.jsonl` 의 `repeat_runs` 5건이 **전부** `dirty=True` 였고 `code_sha` 와
`config_sha` 가 매번 달랐다. v3 과 v5 는 데이터가 바이트 단위로 동일한데
성공률이 4.3% vs 9.3% 다. 차이는 코드·config 인데 **여러 개가 동시에 바뀌었고
커밋으로 되짚어갈 수 없다.** 그래서 어느 변경에도 귀속시킬 수 없다.

추가로 `log_run` 이 `git_rev`·`code_sha` 를 **로그 시점에** 계산한다. 몇 시간 도는
잡에서는 그 트리가 수치를 만든 트리가 아니다 — v6 이 잡 시작 시점에 없던 커밋을
자기 리비전으로 기록했다.

**결정**

1. **조건 비교가 목적인 실행은 커밋 후에만 시작한다.** 더러운 트리에서 나온 수치는
   비교 대상이 아니라 참고값으로 기록한다
2. 계측 도구는 **실행 시작 시점**의 `code_sha` 를 조건에 함께 남긴다
   (`eval/repeat.py` 의 `CODE_SHA_AT_LAUNCH`. 다른 도구는 미적용 — L45)
3. 한 실행에서 바꾸는 요인은 **하나**로 제한한다. 여러 개를 바꿔야 하면 각각을
   별도 실행으로 쪼갠다

**되돌릴 조건**

없다. 이건 취향이 아니라 귀속 가능성의 최소 조건이다.
다만 (3) 은 탐색 단계에서는 완화할 수 있다 — 그때는 결과를 "탐색"으로 표기하고
게이트 판정에 쓰지 않는다.

**파급**

- `eval/repeat.py` 실행 전 경고 추가됨 (커밋 `4a6fb2a`)
- 다른 계측 도구 미적용 → L45
