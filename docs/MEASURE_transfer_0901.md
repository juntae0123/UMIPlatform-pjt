## 무엇을 쟀나

같은 정책을 공칭 도메인(A)과 흔든 도메인(B)에서 같은 시드·같은 물체 배치로
채점하고 `붕괴율 = 1 − (B 성공률 / A 성공률)` 을 낸다.

조건 B 외란 (🟡 설계 판단, 계측값 아님):

| 항목 | 폭 | 무엇을 대신하나 |
|---|---|---|
| 미끄럼 마찰 | ±30% | 조립 오차·표면 상태·마모 |
| 대상물 질량 | ±20% | 부품 편차·재질 |
| 광원 위치 / 확산광 | ±0.10m / ±0.15 | 촬영 환경 |
| 카메라 위치 / 자세 | ±5mm / ±2° | 마운트 조립 오차·재장착 |
| 색 | ±0.15 | 조명 색온도·재질 편차 |

## 이 결과가 말하는 것

**확정** 🟢

1. **val loss 는 이 태스크의 성공률을 예측하지 못한다.** 손실을 낮춰도 성공률이
   움직이지 않았다. 독립 학습 2회로 재현됐다.
2. **`scripted` 의 붕괴율 +0.000 은 "물리에 강하다"가 아니다.** 그 실패는 IK
   도달 불가(기하)이고, A/B 물체 배치가 같으니 실패 시드도 같다. 물리 프로브로
   무효다 (TS_measurement_defects_0901 #4).
3. **조건 B 에서 BC 의 성공이 전부 사라졌다.** 마찰·질량이 아니라 카메라 ±5mm·
   ±2°, 조명, 색만 바꿨는데 전멸이다. 방향은 n 이 작아도 분명하다.

**잠정** 🟡

4. 붕괴율 1.000 / S3·S4 기각 — **근거가 성공 5건 대 0건이다.**
   A=25% 는 5/20 이고 95% 신뢰구간이 약 9~49%, `validity` 문턱 20% 바로 위다.

**계측 자체의 한계 — 이게 이번 실행의 가장 큰 산출물일 수 있다**

같은 `scripted` 가 시드 1000~1019 에서 95%, 2000~2019 에서 70%다. **25%p 차이.**
n=20, p≈0.8 의 95% 신뢰구간 반폭 ≈ ±18%p 로 게이트 폭(20%p)과 거의 같다.
**현재 계측기는 게이트를 분해하지 못한다.** BC 두 블록 합산 5/40 = 12.5%
(CI 약 4.9~26.6%) — 통과도 실패도 확정 불가.

이 지적은 BC 25% 가 나오기 **전에** scripted 불일치로 먼저 나왔다. 게이트는
그대로 두고 n 만 100 으로 올린다 (CI 반폭 ≈ ±9%p).

⚠️ 지금까지 이 프로젝트에서 나온 모든 n=20 성공률에 소급 적용된다.
   scripted "95%" 도 대략 "77~99%" 로 읽어야 한다.
