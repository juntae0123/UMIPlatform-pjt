## 오늘의 큰 정정 3건

### 1. v2·v3·v5 는 같은 데이터다 (TS_provenance_holes_0907)

`audit_demos` 를 셋에 돌렸는데 소수점 6자리까지 같은 수치가 나왔다. 해시로 대조한
결과 **v3 과 v5 는 바이트 단위로 동일**, v2 는 state/action 이 같고 이미지만 다르다.

즉 5일간 "데이터 조건 실험"이라 부른 것 중 **실제로 데이터를 바꾼 것은 v4(dwell)
하나뿐**이다. 나머지는 같은 데이터에 이름만 달랐고, 나는 그 이름을 근거로 인용했다.

그럼 v3 4.3% vs v5 9.3% 는 무엇인가 → `code_sha` 대조: **비결정성이 아니다**
(코드가 실제로 달랐다). 대신 매 실행 코드·config 가 동시에 바뀌고 트리가 전부
더러웠다. **어느 변경에도 귀속시킬 수 없다.** 프로세스 실패이고 내 것이다.
→ D-AI-31

### 2. 3회 반복으로는 조건을 비교할 수 없다

실행 수준 순열검정에서 3 vs 3 의 최소 단측 p 는 1/C(6,3) = **0.05** 다. 어떤 3회

비용을 다시 계산하면 결론이 바뀐다: 학습 1회 22분, V100 10장, GPU당 독립 잡 →
**10시드도 벽시계 22분**이다. → D-AI-30 (탐색 5 / 최종 후보 10 / 고장검사 3)

## 오늘 좁힌 것 — 정지 창

`audit_demos` 로 시연 데이터만 읽었다 (학습·롤아웃·GPU 0회).

첫 가설 "닫기 구간에 팔 델타 0 프레임이 쌓여 L1 중앙값이 0 으로 끌린다" 는
**기각**됐다. `action` 은 명령값이고 `state` 는 실측 관절각이라, 닫는 동안 명령이
상수여도 `action − state` 는 0 이 아니라 추종 오차로 남는다.

그러나 state 6차원에 **그리퍼 위치**가 있다는 구조를 놓치고 있었다. 닫는 동안
그리퍼 state 가 단조 변하므로 닫기 대부분은 관측상 구분된다. 모호한 곳은
**그리퍼가 물체에 물려 포화되고 팔도 멈춘** 창이다. 그걸 직접 재도록 바꿨다.

```
가장 긴 정지 창   22.0틱 = 0.73초   (Q1 = Q3 = 22, 98편 전부 동일)
시작 위치         틱 74             (닫기 시작 8틱 후, 에피소드 141틱)
창 이후 남은 틱   45틱              (= 들기 phase 전체)
```

정책이 보는 것: **구분 불가능한 관측 22프레임에 "유지" 라벨**, 그리고 똑같은 관측에
"들어올려" 라벨 1프레임. L1 이면 중앙값은 "유지"고, 유지하면 관측이 계속 정지하므로
예측도 계속 "유지"다 — 자기유지 고정점 🟡. 틱 102 파지 → 200 동결이 이것과 맞고,
v6 의 `bc 평균 상승 0.70cm` 도 창 안 라벨 크기(최대의 13.5%)와 맞는다.

**v4 가 용량-반응 데이터점이 된다** — dwell 15틱 주입은 이 창을 22→37틱으로 늘린
것이고 0/300 이었다. 두 점이 생겼다. 예측: 창을 줄이면 성공률이 올라야 한다.
(단 두 점 다 3회 실행이라 p=0.05 경계다.)

## 오늘 철회한 것 — "여유 1.3mm" / "51mm 포화" / "물리 능력의 98%"

세 주장 다 같은 뿌리의 계측 산물이었다. `rollout()`·`probe()` 가 `is_success()` 에서
루프를 끊고 `lift_height()` 를 그 뒤에 읽는다 → **성공한 편의 상승량은 판정선을 넘은
순간의 높이**다. 측정이 재려는 것에 의해 종료된다.

`stop_on_success=False` 로 재측정: 달성이 명령의 **88~91% 로 일정**하다. 포화 없음,
능력 문제 없음. 8cm 명령이면 73.2mm 올린다.

단서를 놓친 지점: 명령 6.0/6.5/7.0cm 이 전부 Q1 = 50.0 을 냈다. 서로 다른 명령
높이 셋이 소수점 첫째 자리까지 판정선과 같은 값을 낼 확률은 없다. 거기서 멈췄어야 했다.

철회 범위와 살아남은 것은 MEASURE_demo_lift_margin_0907 §6.
"태스크 설계 문제 / 실물이 더 나쁠 가능성 / HW·PM 확인 필요" 는 **전부 철회**다.

## 그리고 남은 실제 결과 — 천장 손실은 들기 IK 하나다

차단 사항("98편에 잡고 못 든 시연이 섞였나")을 재려고 98편을 재생했다.
**0/98. 데이터는 깨끗하다.** 동결은 데이터가 가르친 것이 아니다.

그런데 달성 상승량이 **중앙 51.3mm, Q1 51.1 / Q3 51.4** 였다. 기준은 50.0mm,
명령은 80.0mm. **여유가 1.3mm 이고 폭 0.3mm 는 변동이 아니라 구조다** — 들기
보간이 45틱에 안 끝나 잘린다 🟡.

이걸로 오늘 셋이 한 줄로 꿰인다:

- 전문가 12~16% 실패 = 기준선 바로 아래로 떨어진 편들
- 관절공간으로 5틱 밀면 얼어붙은 5/5 전부 성공 = **조금만 더 올리면 되는 상태**
- 명령 60mm 가 80mm 보다 성공률 높음 (n=20) = 낮은 목표는 IK 도달 가능해 실제
  실행되고, 높은 목표는 자주 IK 실패로 구간이 통째로 건너뛰어진다

처방은 게이트를 낮추는 것이 **아니라** 달성 상승량을 올리는 것이다. → L49
