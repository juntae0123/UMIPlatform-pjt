# PREREG — 관측 절제 (폐루프) 2026-09-11

작성자: 김준태(트랙B) · 이슈 S15P21A103-34, S15P21A103-35
도구: `tools/probe_obs_ablation.py`

## 질문

**정책이 이미지를 실제로 쓰는가. 어느 카메라가 기여하는가.**

S1 이 실행 계층을 닫았고(ROS2 98~100% 통과), 남은 병목은 **팔 정밀도**로 좁혀졌다 —
실패 에피소드 최근접이 dagger 3.2~4.2mm, v5 12~17mm 인데 scripted 는 0.3mm 다 🟢.

그런데 "팔이 부정확하다"와 **"팔이 물체를 아예 안 본다"**는 밖에서 똑같이 생겼고
**처방이 정반대다.** 이미지가 기여하지 않으면 정책은 관절각만의 함수이고 평균 궤적을
재생할 뿐이다 — 행동 표현·손실 가중·데이터 증량 전부 무의미해진다.

`eval/image_sensitivity.py` 가 이미 있으나 **개루프(교사강요)** 측정이고, 인용되는
"상태만으로 정답의 86%가 설명된다"는 🟢 2026-09-02 로 **`sim_pick_v1` 시절 · 다른
행동공간**의 값이다. 현행 `joint_delta_gripper_binary` 체크포인트에 대한 **폐루프**
측정은 없다. 개루프 민감도가 0이 아니어도 루프를 닫기엔 부족할 수 있다.

## 조건

- 체크포인트: dagger binary seed0/1/2 (+ `--include-v5` 로 v5 binary 선택 가능)
- n=100 · seeds 3000~3099 · render · policy-device cpu · jitter ±50mm · `max_ticks=200`
- 최초 성공 시 종료 (기존 롤아웃과 같은 조건) → `full` 조건이 **6/69/25 를 재현해야 한다**
- 기증자(donor) 에피소드: `seed_base − 1` 로 따로 롤아웃해 틱별 이미지를 캐시한다.
  평가 시드 블록 밖이므로 평가에 누수되지 않는다

## 절제 조건

| 조건 | 무엇 | 성격 |
|---|---|---|
| `full` | 원본 | 기준 · **재현 fixture** |
| `donor_both` | 두 카메라를 기증자 에피소드의 **같은 틱** 이미지로 교체 | **주 판정.** 분포 안, 내용만 틀림 |
| `donor_front` / `donor_wrist` | 한 카메라만 교체 | 카메라별 기여 |
| `freeze_both` | 틱 0 이미지를 끝까지 유지 | 시간 변화 정보 제거 |
| `blank_both` | 0 으로 채움 | 극단값. **분포 밖이라 보조로만 읽는다** |

`donor` 를 주 판정으로 쓰는 이유: `blank` 는 정규화 후 평균에서 멀어 분포 밖이고,
그 하락이 "이미지를 쓴다"가 아니라 "이상한 입력에 망가진다"일 수 있다.
`donor` 는 실제 관측 분포 안에 있으면서 **물체 위치만 틀린** 입력이다.

## 사전등록 판정 (결과 전 확정)

**주 판정: `full` 대비 `donor_both` 성공률 하락폭**

| 하락폭 | 판정 | 다음 |
|---|---|---|
| < 20%p | **이미지를 거의 안 쓴다** | 병목은 팔 정밀도가 아니라 **관측 미사용**. 인코더·증강·데이터로 간다. 행동 표현·손실 튜닝 중단 |
| 20~50%p | **부분 사용** | 이미지를 쓰되 부족하다. 관측 개선과 정밀도 개선을 함께 본다 |
| >= 50%p | **이미지를 쓴다** | 관측 미사용 가설 기각. 팔 정밀도가 진짜 병목이다 |

**보조 판정**

1. `donor_front` 하락이 **5%p 미만**이면 → `cam_front` 가 기여하지 않는다.
   **계약의 카메라 2대 요구(L62)에 직접 영향** — 실물 1대 구성의 근거가 된다
2. `donor_wrist` 하락이 `donor_front` 보다 **2배 이상** 크면 → 손목 카메라가 주력이다.
   카메라 배치·hand-eye 우선순위가 거기로 간다
3. `freeze_both` 가 `donor_both` 보다 **덜** 떨어지면 → 정책이 쓰는 것은 **내용**이 아니라
   **시간에 따른 변화**다 (모션 단서). 정적 물체 위치를 못 읽는다는 뜻
4. `blank_both` 만 크게 떨어지고 `donor_both` 는 안 떨어지면 → 분포 밖 입력에 망가지는
   것이지 이미지를 쓰는 게 아니다. **`blank` 로 "이미지를 쓴다"고 결론 내지 않는다**
5. `full` 이 6/69/25 를 재현하지 못하면 → **계측기 오류. 해석 중단**

## 예측 (실행 전) 🟡

- `donor_both` 하락 **30~60%p** → 부분 사용. 완전 미사용은 아닐 것이다.
  근거: DAgger 데이터는 상태 분포가 넓어 상태만으로 재생하기 어렵고, 닫는 순간이
  scripted 수준(4.9mm)까지 간 것은 물체를 어느 정도 본다는 뜻이다
- `donor_wrist` 하락이 `donor_front` 의 **2배 이상** — 손목 카메라가 주력
- `freeze_both` 는 `donor_both` 보다 **더** 떨어진다 (정보가 더 적다)
- seed0(6/100)은 절대 하락폭이 작다 — 원래 낮아서 떨어질 자리가 없다.
  **비율이 아니라 절대 %p 로 읽는다**

**크게 빗나갈 때**: `donor_both` 하락이 20%p 미만이면 "팔 정밀도가 병목"이라는
지금까지의 해석이 틀린 것이고, **관측 미사용**이 진짜 원인이다. 그러면 D-AI-38 이후의
우선순위를 전부 다시 세워야 한다.
