## 1. 부분 수집분을 조용히 재사용할 뻔했다

**증상** 일괄 실행 스크립트가 `[1/5] 이미 있음 — 건너뜀` 을 출력하고 학습으로
넘어갔다. 그 디렉터리에 몇 편이 들어 있는지는 아무도 몰랐다.

**왜 위험한가** 실행 로그는 "100편"이라고 말하는데 실제로는 다른 편수로 학습이
돈다. 하류 어디에서도 그 사실이 드러나지 않는다. 수치를 나중에 인용할 때
조건이 틀린 채로 인용하게 된다.

**어떻게 드러났나** 이 판정 자체가 잡은 게 아니다. 바로 다음 줄에서 내가 쓴
`verify_dataset.py --dataset` 이 인자 오류로 죽어서 우연히 멈춘 것이다.
게이트가 아니라 오타가 막았다.

**1차 수정 — 이것도 틀렸다** 파일 수가 요청 편수보다 적으면 중단하도록 했다.
그러자 **정상 완료된 98편을 거부했다.** 수집은 IK 도달 불가 배치를 버리므로
100편 요청이 98편을 남기는 것이 정상이다. 판정 기준을 "요청 편수"로 잡은 것이
틀렸다.

**2차 수정** `collect.py` 는 루프가 전부 끝난 뒤에만 `dataset.json` 을 쓴다.
그 파일이 이미 완료 표식이었다. 코드에 있던 표식을 안 보고 편수로 대신 판단한
것이 애초의 실수다.

```
인덱스 있음        → 완료본. 파일 수와 인덱스 항목 수 대조 후 재사용
인덱스 없고 npz 있음 → 중단분. 멈춘다
둘 다 없음         → 수집
```

## 2. `verify_dataset.py --dataset` — 인자 오용

**증상** `error: unrecognized arguments: --dataset`

**원인** 이 도구는 위치 인자를 받는다. 스크립트를 쓸 때 다른 도구들의 인자
형태를 보고 유추했고, 확인하지 않았다.

**교훈** 일괄 실행 스크립트에 넣는 명령은 전부 `--help` 로 대조하고 넣는다.
이번엔 `collect_sim` 과 `train_bc` 만 확인하고 `verify_dataset` 을 빠뜨렸다.

## 3. 성공 지도 도구가 코드 버전이 다른 실행을 합쳤다

**증상** `scripted` 성공률이 48.7% 로 나왔다. 실제는 95%다.

**원인** `EXP_LOG.jsonl` 의 모든 시행 기록을 정책 이름으로만 모아 합쳤다.
로그에는 `scripted` 가 0% 나오던 옛 빌드의 실행분이 남아 있다. 코드 버전·지터·
시드 블록이 다른 측정을 합치면 **실제로 존재한 적 없는 설정을 기술하는 숫자**가
나온다. 이 프로젝트 절대원칙 3(모든 수치에 측정 조건 병기) 위반이다.

**수정** 시행을 EXP_LOG 레코드 단위로 묶고, 기본값은 (실험, 조건, 시드 블록)
마다 최신 실행 하나만 쓴다. 여러 실행을 합치면 코드 버전이 섞였는지 검사해
경고한다.

**왜 위험한가** 48.7% 는 그럴듯한 숫자다. 95% 를 이미 알고 있지 않았다면
발견되지 않았을 것이다.

## 4. `scripted` 는 물리 외란 프로브로 쓸모가 없다

**증상** 전이 계측에서 `scripted` 가 조건 A 와 B 에서 **소수점 세 자리까지
동일한** 70.0% 를 냈다. 두 번의 실행에서 모두.

**원인** `scripted` 는 특권 정보(물체 정답 위치)를 읽고 IK 로 목표 자세를
푼다. 그 30% 실패는 마찰·질량이 아니라 **도달 불가(기하)** 다. 물체 배치가
A/B 에서 동일하므로 실패하는 시드도 동일하다.

**설계 오류** 나는 `scripted` 를 "물리 외란만 격리해서 보여주는 기준선"으로
넣었다. 그 역할을 못 한다. 붕괴율 +0.000 을 "물리에 강하다"로 읽으면 틀린다.

**조치** 전이 계측에 `--skip-scripted` 를 추가했다. 렌더 시간의 절반을 차지하고
정보는 주지 않는다. 물리 민감도를 재려면 다른 프로브가 필요하다 — 미해결.

## 5. (부수) tmux 마우스 스크롤이 잡을 재실행시켰다

tmux 의 마우스 모드가 꺼져 있으면 휠이 방향키로 변환돼 셸 입력 버퍼에 쌓인다.
스크립트가 끝나고 프롬프트가 돌아온 순간 그것이 bash 히스토리 조회로 해석돼
직전 명령이 다시 실행됐다.

결과적으로는 독립 재학습 2회를 얻어 이득이었지만, 의도한 실행이 아니었다.
`set -g mouse on` 을 `~/.tmux.conf` 에 넣는다.
