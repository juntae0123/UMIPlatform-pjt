## 2. 절벽이지 기울기가 아니다

78% → 0% 가 f=1.00 과 f=0.80 사이에서 일어난다. 중간이 없다.

실패의 **모양**이 결론을 떠받친다:

```
접촉률 99% · 최근접 중앙 0.2mm
```

팔은 정확히 맞는 자리로 가서 물체에 닿는다. **닿고도 못 쥔다.**
"엉뚱한 데로 갔다"가 아니라 "맞는 데 가서 못 닫았다"다.
이것이 0911 실수집분이 처한 상태와 같은 모양이다 —
`MEASURE_gripper_crosscheck_0912.md` 의 시계열도 개방에서 한 번 내려와
38~40mm 에서 평평해진 뒤 더 안 내려간다.

물리적으로도 당연하다. 2cm 큐브를 쥐려면 턱이 2cm 폭까지 와야 하는데,
명령 바닥값이 그 위면 힘이 안 실린다. **그래서 이 f 임계는 일반 상수가 아니라
물체 폭에 묶인 값이다.** 이 조건에서는 "거의 끝까지 닫아야 한다"로 읽는다.

## 3. 예측 대비 — 빗나간 부분을 적는다

사전등록 7절에 **f=0.35 에서 0~5%** 로 적었다. 그 부분은 맞았다 (0%).

**빗나간 것: f=0.80 도 0% 일 줄은 몰랐다.** 폐쇄량이 80% 면 어느 정도는 살아남고
거기서부터 기울기가 보일 거라 암묵적으로 가정했는데, 절벽이었다.
0912 오전에 손목 전용을 −8~18%p 로 예측했다가 +26.0%p 가 나온 데 이어
같은 날 두 번째 예측 오류다 — 방향은 맞고 크기를 못 맞춘다.

## 4. 한계

- **전부 시뮬이다.** 시뮬 성공률은 sim2real 갭의 **하한**이다.
  여기서 무너지면 실물에서도 무너지지만, 버틴다고 실물을 보장하지 않는다
- 물체가 **2cm 큐브 한 종**이다. 다른 크기·형상의 임계는 모른다
- 천장 정책(scripted)이다. 학습 정책의 임계가 같다는 근거는 없다
- f 목록은 착수 전 확정했고 결과를 보고 늘리지 않았다.
  절벽 위치(1.00~0.80 사이)를 좁히려면 **별도 사전등록**이 필요하다

## 5. 판정과 후속

| | 내용 |
|---|---|
| 판정 | 사전등록 기준 `f=0.35 < 10%` → **재수집 필수 판정의 근거가 된다** |
| 에스컬레이션 | HW·PM — 0911 대상물 실측 폭 + UMI 그리퍼 폐쇄 사진 1장 |
| 수집 프로토콜 | 재수집 시 "**끝까지 쥔다**"를 명시. 지금 프로토콜에 그 문장이 없다 |
| 미측정 | 절벽 위치 정밀화 (f=0.85~1.00) · 물체 크기별 임계 · 학습 정책의 임계 |

**주의 — 이 수치가 답하지 않는 것.** "실물에서 38~40mm 로 쥐면 실패한다"를
직접 보인 것이 아니다. 보인 것은 "이 시뮬 태스크에서 폐쇄량이 부족하면
팔이 맞게 가도 파지가 성립하지 않는다"이다. 대상물 실측 폭이 오면
그때 실물 조건으로 다시 읽는다.
