# PREREG — 폐쇄 시각 상한 계측기 (oracle-best-tick) 2026-09-11

작성자: 김준태(트랙B) · 이슈 S15P21A103-34

## 왜

현행 `oracle` 은 `norm(pinch − (object + grasp_z)) <= grasp_tol_m(0.005)` 일 때 닫는다.
**v5 seed0 에서 `never_closed` 가 91/100 이다** 🟢 — 정책의 실패 에피소드 최근접
수평거리 중앙이 14.3mm 라 5mm 조건이 거의 발동하지 않는다. 즉 기존 oracle 수치
(v5 3/100, DAgger 48/21/24)는 성능이 아니라 **tolerance 미충족률**이다. L72.

tolerance 확대는 반쪽이다. ±15mm 에서 재생 성공률이 1/4 이므로(🟢) 발동시켜도 놓친다.

## 무엇을 재는가

**폐쇄 시각의 상한.** 에피소드마다 "가장 가까웠던 틱"에 닫는다. 인과적으로는 불가능
(미래를 봐야 한다)하지만 상한 계측기로는 정당하다. 2패스로 구현한다:

1. 1패스 — 그리퍼를 계속 열고 롤아웃, 프레임별 `pinch_to_object` 를 기록해 최근접 틱 t* 를 찾는다
2. 2패스 — 같은 시드로 다시 돌리며 t* 에 닫는다

`fixed` 스윕과 짝을 이룬다: fixed = **고정 시각**의 상한, 이것 = **에피소드별 최적 시각**의 상한.
**둘의 차이가 "닫는 시각을 관측으로 정할 수 있다면 얼마나 더 버는가" 다.**

## 조건

- checkpoint: `sim_pick_v5_seed0.pt` (기존 fixed 스윕과 같은 대상)
- n=100 · seeds 3000~3099 · render · policy-device cpu · jitter ±50mm · 단일 잡
- learned 재현 fixture `--expected 11` 을 유지한다 (오늘 트리 eval_rollout 2회 확인값 🟢)
- 1패스·2패스가 같은 시드에서 **동일한 팔 궤적**을 내는지 먼저 확인한다.
  다르면 이 계측기는 성립하지 않는다 (롤아웃이 결정적임은 이미 확인됨 🟢)

## 사전등록 판정

| 결과 | 뜻 |
|---|---|
| oracle-best-tick > fixed 최고(37%) + 15%p | 시각을 맞히면 크게 번다 → **시각 예측을 정책 밖으로 뺀다** (별도 헤드·분류기) |
| 37~52% | 시각으로 버는 몫이 작다 → 병목은 팔이다. 데이터·관측으로 간다 |
| <= 37% | 계측기 또는 해석이 틀렸다. 상한이 고정 시각보다 낮을 수 없다 |

## 예측 (실행 전) 🟡

**40~55%.** fixed 최고 37% 보다 높되 크게는 아니다. 근거: 최근접 중앙이 14.3mm 이고
±15mm 재생 성공률이 1/4 이므로, 최적 시각에 닫아도 절반 이상 놓친다.

**60% 를 넘으면 "v5 의 병목은 팔" 이라는 내 해석이 틀린 것이고**, E1 의 천장 해석부터
다시 세워야 한다.

## 해석 제한

- 상한이다. 배포 가능한 처방이 아니다 — 미래를 보는 조건이다
- 체크포인트 1개다. 학습 실행 간 25%p 편차 실측이 있으므로 v5 계열 전체의 상한이 아니다
- `verdict` 필드는 체크포인트 1개 실행에서 무효다 (L71)
