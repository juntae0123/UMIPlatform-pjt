## 1. 조작 정책 — `BCNet` (자체 구현)

`AI/policy/bc.py`. 이름 있는 공개 모델이 아니라 우리가 만든 최소 구성이다.

| 항목 | 값 | 근거 |
|---|---|---|
| 입력 | 이미지 (3,224,224) uint8 × **2대** (`cam_front`, `cam_wrist`) + 관절 state (6,) | 계약 0.2.0 |
| 인코더 | ConvEncoder — 3×3 stride 2 × 4단 [32,64,128,256] + GroupNorm + ReLU → AdaptiveAvgPool → Linear 256. **카메라별 분리(separate)** | `configs/train/bc.yaml` |
| 헤드 | Linear 512 → 256 → 6, ReLU, Dropout 0.1 | 〃 |
| 파라미터 | **1,307,974 (fp32 약 5.0MB)** | 🟢 학습 로그 |
| 출력 | 팔 5관절 = `action − state` 잔차, 그리퍼 = 절대 명령 (`joint_delta_gripper_abs`) | D-AI-28 |
| 손실 | L1, 데이터셋 통계로 관절별 표준화 | 〃 |
| 사전학습 | **없음.** ImageNet ResNet 은 다음 후보 🟡 | `policy/bc.py` ConvEncoder docstring |
| 현재 성능 | 시뮬 **5.7%** (11/2/4%, n=300, 3회) · 게이트 20% 미달 | 🟢 MEASURE_bc_repeat_0902 |

**의도적으로 가장 단순한 것을 골랐다.** BC 수치를 먼저 재지 않으면 나중 모델이 잘 돼도 이유를 설명 못 하고 안 돼도 원인(데이터 vs 모델)을 좁힐 수 없다.

### 다음 후보 (전부 🟡 미착수)

| 후보 | 무엇이 달라지나 | 착수 조건 |
|---|---|---|
| ImageNet 사전학습 ResNet 인코더 | 작은 데이터셋에서 유리할 가능성. **이미지 정규화 통계가 함께 바뀐다** — 슬쩍 넣을 게 아니라 D- 기록 대상 | 데이터 스케일링(98→400) 결과 이후 |
| ACT (Action Chunking Transformer) | 한 번에 여러 스텝을 낸다. 지금은 단일 스텝 | 〃 |
| Diffusion Policy | 다봉 분포 표현 | 〃 |

**BC 게이트 전에 이쪽으로 넘어가지 않는다.** 프로젝트 원칙.

## 2. 지시 이해 — VLM

이미지 + 텍스트 지시 → **스킬 5종 × 목적지 5종 enum + 기권**. 자유 문장 생성 없음 (D-AI-24).

| | SmolVLM2-500M-Video-Instruct | Qwen2.5-VL-3B-Instruct |
|---|---|---|
| fp16 argmax 일치 | **0.9961** 🟢 | 0.9909 🟢 (게이트 0.99 를 간신히) |
| 최대 로짓 절대차 | 0.221 🟢 | **24.558** 🟢 — 일부 위치에서 크게 튄다 |
| vocab | 약 49,152 🔵 | 약 151,936 🔵 |
| Jetson Q4 예상 | 약 0.3GB 🟡 | 약 2GB 🟡 |
| git rev (검증 시점) | b015c85 | da250bb |

**주 후보는 SmolVLM2-500M.** 이유는 크기가 아니라 여유도다 — fp16 게이트 여유가 7배 크고, Jetson 8GB 를 정책과 나눠 써야 한다 (이슈 42 **미검증**).

**아직 안 잰 것**: 스킬 선택 정확도, grounding 정확도, 라이선스. fp16 안전성은 "쓸 수 있나"이지 "잘 하나"가 아니다.

### "최신 대형 모델로 학습하고 젯슨엔 경량" 에 대한 답 🟡

큰 모델을 파인튜닝해도 **작은 모델이 그 가중치를 물려받지 않는다.** 가능한 건 둘:

1. 큰 모델을 **라벨러(교사)** 로 → 그 라벨로 작은 모델 학습.
   **시뮬 데이터에는 무의미하다** — 시뮬레이터가 정답을 이미 안다 (D-AI-17).
   **실물 사진 라벨링에는 의미가 있다.** 그때 검토한다
2. 로짓 증류 — 같은 계열·토크나이저여야 하고, 우리 출력은 25지선다다. 증류할 복잡도가 없다

우리 과제는 개방형 언어가 아니라 25지선다다. 대형 모델의 강점이 쓰이는 자리가 아니다.
→ **경량으로 M0 게이트 먼저.** 실물 이미지 단계에서 1번이 필요해지면 그때 붙인다.

## 3. 음성 → 텍스트 (STT) — 미정, Stretch W8

| 항목 | 상태 |
|---|---|
| 모델 | **미정.** API 우선 🟡 (Jetson 8GB 를 VLM+정책이 이미 쓴다) |
| 온디바이스 후보 | Whisper 계열 🔵 — 시간 남을 때만 |
| 학습 데이터 | API 경로는 없음. 도메인 어휘 사전(스킬·목적지 enum)을 후처리에 |
| 위치 | 음성 → 텍스트 → VLM. **STT 는 VLM 의 입력을 만들 뿐 판단하지 않는다** |

**안전 명령은 VLM 에 넣지 않는다** 🟡 — "멈춰" 같은 개입 명령은 키워드 매칭이 맞다. 정지를 모델 추론에 맡기지 않는다.
