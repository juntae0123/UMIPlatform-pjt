## 1. 왜 A″(blend) 보다 B′ 가 먼저인가

외부 자문의 핵심 제안이다. **교사강요 관측에서 BC 가 실제로 출력한 action 시퀀스가
이미 가장 정확한 residual donor 다.** 부트스트랩 설계가 필요 없다.

```
A  :  a_t = a_t^demo                 기록된 정답 action 재생
B′ :  a_t = π(o_t^demo)              교사강요 예측 시퀀스를 미리 저장해 개루프 재생
C  :  a_t = π(o_t^actual)            실제 BC 폐루프
```

B′ 는 signed bias · 관절 간 공분산 · 위상 의존성 · 시간 상관을 **전부 원본 그대로**
보존한다. 블록 길이도, 주입 공간도, 배율도 고를 필요가 없다.

**세 조건은 반드시 같은 설정에서 재야 한다.** 기존에 알고 있는
"재생 98/98" 과 "BC 0/20" 은 **물체 조건이 다르다** — 전자는 물체 고정,
후자는 지터 ±50mm 다. 그래서 C 를 **물체 고정으로 다시 잰다.**

## 4. 단계 1 — A / B′ / C 삼자 비교 (n=98, 물체 고정)

### 사전등록 판정

n=98 Wilson 95% (z=1.96) 기준. 기록: 98/98 → 하한 **96.2%**.

```
J1. B′ 의 Wilson 상한 < 20%   (기존 롤아웃 게이트)
    → 교사강요 관측에서의 예측 오차만으로 배포 기준 아래.
    → 되먹임 없이도 실패가 설명된다.
    → 다음: one-step 정확도 · 행동 표현 · 시퀀스 모델.
       DAgger 착수하지 않는다.

J2. B′ 의 Wilson 구간이 A(96.2~100%) 와 겹침
    → 교사강요 예측 오차는 개루프에서 검출 가능한 피해를 주지 않는다.
    → C 가 실패하면 그 차이는 되먹임·상태분포에서 온다.
    → 다음: O(α) vs C(α), 그리고 exact-state phase start.

J3. B′ 가 A 보다 유의하게 낮지만 상한이 20% 이상 (구간 비겹침)
    → 예측 오차가 일부 기여하나 폐루프 0% 를 단독 설명하지 못한다.
    → 다음: 단계 2 전체 실행.

J4. B′ 와 C 가 모두 J1 수준
    → 두 원인 모두 기여 가능. 분리하려면 단계 3(H-burst)이 필요.
```

**금지**: 이 결과로 게이트를 옮기지 않는다. 구간이 겹치면 n 이 아니라
**독립 checkpoint 수**를 늘린다 (학습 실행 간 25%p 변동, §0 규칙 8).

**1차는 checkpoint 1개 정찰이다. 처방을 확정하지 않는다.**
J1 또는 J2 로 갈리면 독립 checkpoint 3개로 재실행해 확정한다.
조건 순위를 매겨야 하면 5개로 늘린다 (3 vs 3 순열검정 최소 단측 p = 0.05).

## 5. 단계 2 — O(α) vs C(α) (단계 1 이 J2·J3 일 때만)

```
O(α) :  a_t = (1-α)·a_t^demo + α·π(o_t^demo)      개루프, 교사강요 출력
C(α) :  a_t = (1-α)·a_t^demo + α·π(o_t^actual)    폐루프, 실제 관측
```

물리 rad 공간에서 혼합 → 관절 한계 clip → T0 검증 경로 실행.

```
α ∈ {0, 0.125, 0.25, 0.375, 0.5, 0.75, 1.0}      두 곡선 모두 같은 격자
```

**엔드포인트 동일성이 계측기 검증이다**: O(0)=C(0)=A, C(1)=단계 1 의 C, O(1)=단계 1 의 B′.

### 사전등록 판정

```
K1. 같은 α 에서 C(α) 의 Wilson 상한 < O(α) 의 하한 (비겹침)
    → 실제 관측에 다시 질의하는 되먹임이 추가 손실을 만든다 (feedback penalty)

K2. 두 곡선이 전 구간에서 구간 겹침
    → 되먹임 의존성이 작다. 외생적 잔차 모델이 실제 BC 를 잘 근사한 것

K3. 비단조 (중간 α 가 양 끝보다 낮음)
    → 계측기 오류로 보지 않는다. 혼합 목표가 만든 실제 현상일 수 있다.
       V0 검증이 전부 통과했으면 현상으로 기록한다
```

**점 추가 규칙 (사전등록)**: 결과를 본 뒤 임의로 α 를 추가하지 않는다.
전이 구간이 한 칸 안에 있으면 **그 칸을 반 간격으로 한 번만** 세분화한다. 그 이상은 없다.

관절 조건 — primary 는 all-joint, 진단용으로 arm-only / gripper-only 를 따로 돌린다.
⚠️ **arm-only 의 α=1 은 BC 전체 롤아웃이 아니다** (BC 팔 + 전문가 그리퍼).
전체 BC 엔드포인트 검증은 all-joint 에서만 성립한다.

## 6. 단계 3 — exact-state phase start · H-burst (단계 1·2 가 갈릴 때)

기록 에피소드의 시뮬 상태를 이벤트 시점에 복원하고 거기서 BC 를 시작한다.
복원 대상: `qpos`, `qvel`, 물체 pose·velocity, actuator state, sim time.
**계측기 검증**: 복원 후 기록 action suffix 를 실행하면 원본과 성공·이벤트 틱이 일치해야 한다.

이벤트: approach 시작 / descend 시작 / close 시작 / first contact / lift 시작

H-burst: 정확한 상태에서 BC 를 **H 틱**만 실행하고 기록 action suffix 로 복귀. `H ∈ {1, 5, 15, 30}`.

```
H=1 부터 실패          → 그 위상의 단일 BC action 이 회복 불가 상태를 만든다
H 증가에서만 실패      → horizon 의존 누적
suffix 가 항상 복구    → BC 오차는 있으나 개루프 위치 목표가 복원 가능
close/contact 만 민감  → 접촉 이벤트 타이밍 문제
```

⚠️ **선행 검증**: suffix 가 알려진 작은 섭동에서 실제로 복구 능력이 있는지 먼저 확인한다.
suffix 가 원래 복구 능력이 없으면 H-burst 결과를 과대해석하게 된다.

## 7. 단계 4 — residual block bootstrap (마지막)

단계 1~3 으로 결론이 안 날 때만. 순서:

1. episode 전체 signed residual 시퀀스 (블록 길이 선택 불필요) ← 우선
2. phase 단위 donor (APPROACH / DESCEND / CLOSE / LIFT), 5관절 벡터를 함께 뽑는다
3. ACF 기반 길이 — **알고리즘을 결과 전에 고정한다**:
   위상·관절별 centered residual ACF 에서 `|ρ(k)| < 0.1` 이 3개 연속 lag 유지되는
   최초 k 의 팔 5관절 최댓값. 최소 3틱, 최대 해당 위상 길이. 위상 경계를 넘지 않는다.
   **signed mean 은 ACF 계산에서만 제거하고 주입에는 원래 bias 를 보존한다.**

배율 1× 는 **실제 signed `pred − demo` residual 그 자체**다.
`action − state` 는 추종오차이므로 배율 기준으로 쓰지 않는다.
