## 새로 확정된 것 셋

### ① 8%p 는 전부 학습 분산이다

평가 비결정성이 0 이 됐으므로(L37 해소) 1~9% 폭은 **학습 시드만으로** 생긴다.
**최고와 최저가 9배 차이난다.** 단일 학습의 단일 수치로 무엇도 비교할 수 없다는
프로젝트 규칙이 이 수치로 다시 확인됐다. 앞으로 학습 3회는 최소치이고, 처방 효과가
8%p 보다 작으면 3회로는 못 잡는다.

### ② val 이 처음으로 롤아웃 **순위**를 맞췄다 (episode 분할)

```
val 0.05333 < 0.05721 < 0.06939   →   롤아웃 9% > 3% > 1%   (3/3 일치)
최종 epoch val 로도 같은 순서 (0.05612 < 0.06055 < 0.07520)
```

sample 분할 시절에는 순서가 맞지 않았다 🟢 (v2: val 0.040/0.045/0.047 → 11/2/4%).
**episode 분할이 처음으로 일반화를 재고 있다는 정황이다.**

⚠️ **n=3 이다. 세 개가 우연히 순서 맞을 확률은 1/6 ≈ 17%.** 확정이 아니다.
R-AI-8(best-val 로 체크포인트 선택) 을 되살릴 근거로는 아직 부족하다.
검증 방법: 학습 6회 이상에서 val 순위와 롤아웃 순위의 순위상관을 잰다. 미착수.

### ③ 실패는 닫는 순간의 위치 오차다 — 3회 모두

닫는 순간 거리 **15.7 / 16.1 / 23.6mm**. 실측 재생 허용오차는 ±15mm 에서 **1/4** 다.
정책은 성공이 25% 이하인 거리에서 그리퍼를 닫고 있고, 실제 성공률은 그보다 낮다.
scripted 는 같은 지표가 **4.7mm** (±5mm 4/4 구간) 이고 84% 다.

**최근접 → 닫는 순간 사이에 거리가 +6.3 ~ +11.7mm 벌어진다.** 접근은 하고 유지를 못 한다.

### 이상 신호 — seed2 의 조기 닫힘

seed2 는 **턱 접촉 7%** (다른 실행 78~84%), **닫은 틱 중앙 44** (다른 실행 64~69).
물체에 도달하기 전에 닫고 그대로 끝난다. 같은 데이터·같은 설정인데 학습 시드만
다른 실행이 **질적으로 다른 실패 양식**을 냈다. ①의 8%p 가 단순한 정도 차이가 아니라는 뜻이다.
