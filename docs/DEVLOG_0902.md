## 결함 4·5번 — 어떻게 좁혔나 (TS §4·5)

3건 고친 뒤 재검사에서도 0% 였다. 원인 후보를 셋으로 쪼개는 계측기(`trace_execution`)를 먼저 만들었다.

```
A 기록 행동 재생   → 성공 (실행 경로 정상, 계측기 자체 검증)
B 교사강요 예측    → 오차÷델타 1.03 (자명한 예측기 수준)
C 폐루프 t=0       → 입력 완전 일치, 출력 0.62 차이
```

입력이 같은데 출력이 다르면 네트워크다. `run_epoch` 학습 호출이 표준화 인자를 위치 인자에 밀려 누락 →
학습은 raw 델타, 추론은 역표준화 → 델타가 std 만큼 한 번 더 축소. **어시스턴트 판정 오류 동반**: "train 0.7% = 외웠다"는 raw 단위를 표준화 단위로 나눈 것. 진짜 신호 val 0.732 ≈ baseline 0.761 이었다.

고친 뒤: 팔 0.14~0.20 통과, **그리퍼 1.07** — 델타가 141스텝 중 124스텝 정확히 0, L1 최적 = 중앙값 0.
→ 그리퍼만 절대 명령 (D-AI-28). 폐루프 첫 성공.
