## 결정에 주는 것

1. **실행 경로는 ROS2 다.** direct-motor 는 1.5Hz 를 요구하므로 30Hz 정책에 못 쓴다
2. **ROS2 처방은 마이크로라디안 마진 하나다.** 남은 선택지 둘:
   (a) ROS·HW 에 URDF 소수 자릿수를 `configs/so101.yaml` 과 맞춰달라고 요청
   (b) 우리가 명령을 URDF 한계로 클램프 (패스 B 가 무해함을 실측 — 성공률 ±0%p)
   **(b) 를 우리 쪽에서 먼저 넣고 (a) 를 병행 요청한다.** (b) 는 즉시 가능하고 되돌리기 쉽다
3. **폐쇄 시각 예측에 투자할 값이 작다.** 완벽히 맞혀도 +3~14%p 다.
   → `PREREG_oracle_best_tick_0911.md`(v5 대상)의 우선순위를 내린다.
   **남은 병목은 팔 정밀도와 학습 불안정(6/69/25)이다**
