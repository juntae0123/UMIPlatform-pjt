## 2. 데이터 출처 4종

### 2-1. 사람 시연 (UMI, 메인)
- 기기: Galaxy S23, ARCore 6DoF pose + IMU (D-AI-21). L33: S22/S23 확정 확인 필요
- 앱 → 서버 전송: **ZIP 무압축** 1편 = jpg 프레임들 + csv 2개(pose, 요청한 `frames.csv` 프레임 타임스탬프) + txt 2개(메타). MW 회신 대기
- 변환 체인 🟡: ARCore 카메라 pose × `T_cam→tcp`(HW 제공, **실측값 L30 미확보**) → t₀ 상대화 → 축 remap → **IK → 관절각** → 계약
- 그리퍼 개폐 신호의 출처 — **앱/HW 확인 필요.** ARCore 는 pose 만 준다
- 수집 계획: 단계식 **20 → 검증 → 100 → 게이트 → 나머지.** 스킬당 150편 목표 (🟡)
- 수집 전 필수 계측: L29 pose↔RGB 타임스탬프 오프셋, L30 hand-eye, L24 5축 재현 불가 폐기율

### 2-2. 시뮬 (MuJoCo 3.12, 보조)
- `datasets/sim_pick_v2` 🟢: scripted pick 98편, 13,818샘플, 물체 xy ±50mm, 계약 0.2.0 위반 0
- 용도: 학습 루프·계측기 검증, 데이터 스케일링 실험(98→400 예정), 도메인 전이 붕괴율(D-AI-18)
- **시뮬 성공률은 최종 지표가 아니다** — 실물 갭의 하한

### 2-3. VLM 미세조정 데이터 (D-AI-17, 이슈 112)
- 시뮬 렌더 + 자동 라벨. 출력은 enum(스킬 5종 + 목적지) + **기권**(confidence < 0.70). 자유 텍스트 생성 없음
- 모델 후보 🟢 fp16 검증: Qwen2.5-VL-3B / SmolVLM2-500M. Jetson 8GB 에 정책과 함께 (이슈 42 미검증)
- 실물 이미지로 M0 게이트 재측정 필요 (렌더 대비 정확도 −0.15 이상이면 재설계)

### 2-3b. STT — VLM 전단계 (Stretch W8, 신현우 확인 "합니다")
- 위치: 마이크(HW) → STT → **텍스트 지시** → VLM. VLM 은 텍스트+이미지를 받아 enum 을 낸다. STT 는 VLM 의 입력을 만드는 단계이고 별도 판단을 하지 않는다
- 방식: **API 우선** (Jetson 8GB 예산을 VLM+정책이 이미 쓴다 — 이슈 42 미검증). 온디바이스(Whisper 계열)는 시간 남을 때만
- 필요한 데이터:
  - API 경로 — 학습 데이터 없음. 다만 **도메인 어휘 사전**(스킬 5종 이름, 목적지 5종, 부품 호칭)을 프롬프트/후처리에 넣는다. 이 목록은 `contract/ids.py` 의 enum 과 같아야 한다
  - 미세조정 경로 — 현장 소음 환경의 지시 발화 녹음 + 전사. **수집 계획 없음.** 필요해지면 그때 이슈로
- 계측할 것: (1) 스킬·목적지 이름 인식률 (enum 5×5 = 25 조합), (2) STT 지연(ms) — 30Hz 제어와는 무관하지만 사용자 체감, (3) 소음 환경 인식률. 게이트는 착수 전에 정한다
- 실패 처리: 인식 결과가 enum 에 매핑되지 않으면 VLM 의 기권과 같은 경로로 **되묻기**. 임의 추측으로 로봇을 움직이지 않는다
- 자연스러운 흐름(현우님 지적): 평소엔 클릭·자동 동작이고 음성은 **개입**(멈춰 / 다시 / 저건 왼쪽) 용도가 자연스럽다. 이건 UX 결정이라 MW·FE 와 함께

### 2-4. 평가 데이터
- 롤아웃 시드 블록(3000~3099, 3회 동일) + `EXP_LOG.jsonl` (실험 1건 = 1줄, git rev 포함)
- 실물 평가: **n=100 실물 롤아웃**이 정답. 아직 없음

## 4. "학습이 잘됐다"의 기준 (신현우·준태 질문에 답)

**손실이 아니다. 롤아웃 성공률이다.** 코드에 결과 보기 전 고정돼 있다 (`contract/skills.py`):

| 상수 | 값 | 뜻 |
|---|---|---|
| `ROLLOUT_GATE` | 0.20 | 성공률 > hold/zero + 20%p |
| `GATE_MIN_N` | 100 | 한 번의 평가에 100편 |
| `GATE_MIN_RUNS` | 3 | 학습 3회 반복, 평균·범위 보고 |

실측 근거 🟢: val 0.00547→0.00517 인데 성공률 0%→0% (09-01). 오늘 5.7%(n=300)도 val 순서와 무관.
레지스트리(D-AI-23)는 게이트 기록 없는 정책을 **거부**한다 → 백엔드 "배포 가능" 판정이 이 값이다.

UMI 실데이터의 지표는 어디서 나오나 — **실물 롤아웃**이다. "촬영 영상을 시뮬에 트윈해서 검증"은 두 가지로 나눠야 한다:
- 궤적 **실행가능성**(IK 도달·관절 범위·5축 재현) 검사 → 시뮬로 할 수 있고 해야 한다 (이슈 113). 수집 중 즉시 폐기율을 준다
- 정책 **성능** 검증 → 시뮬은 하한만 준다. 최종 판정은 실물 n=100
