# MEASURE — 실패 원인은 폐루프 오차 누적이다 (2026-09-07)

작성 김준태(트랙B) · 이슈 S15P21A103-35

## 결론

**네트워크는 정상이다. 실행 경로도 정상이다. 폐루프에서만 무너진다.**

한 스텝 예측 오차는 시연 이동량의 5~10% 로 작은데, 그 오차 위에 다음 예측을 쌓으면서
**매 10틱 약 2배**로 발산한다. 그리고 발산한 관측이 다시 예측을 흔드는 **되먹임**이 있다.

정밀도 문제도, 데이터량 문제도, 학습 목표 문제도 아니다.

## 근거 1 — A·B 통과, C 만 실패 🟢

`tools/trace_execution.py --episode datasets/sim_pick_v5/ep_00000.npz
--policy-ckpt checkpoints/bc/sim_pick_v5_seed1.pt`

| 절 | 내용 | 결과 |
| --- | --- | --- |
| **A** | 기록된 행동을 그대로 되먹임 | **성공** · 128틱 · 상승 5.139cm · 최대편차 0.000203 |
| **B** | 기록 관측을 넣었을 때의 예측 | **통과** · 오차/델타 0.222 (< 0.30) |
| **C** | 폐루프 (자기 예측으로 진행) | **실패** · 상승 0.0cm |

A 되고 B 되는데 C 만 안 된다 — compounding error 의 교과서적 서명이다.

B 관절별 비율(오차÷델타): `[0.071, 0.053, 0.055, 0.040, 0.095, 0.308]`
그리퍼(0.308)만 0.3 을 넘고 팔 5관절은 4~10% 다.

## 근거 2 — 지수 발산과 되먹임 🟢

C 절, 롤아웃 관측이 기록과 갈라지는 정도:

| t | state 차 | image 차(계조) |
| --- | --- | --- |
| 1 | 0.000718 | 0.28 |
| 2 | 0.001480 | 0.57 |
| 5 | 0.003677 | 0.71 |
| 10 | 0.007747 | 1.19 |
| 20 | 0.015796 | 2.40 |
| 40 | 0.148242 | 8.53 |
| 70 | 0.405892 | 6.92 |

**t=1 부터 이미 갈라진다.** 특정 구간에서 갑자기 벌어지는 것이 아니다.
t=20 까지 매 10틱 약 2배, 이후 가속.

되먹임 고리:

```
state 0.0007 갈라짐 → image 0.28계조 갈라짐 → 예측이 달라짐 → state 더 갈라짐
```

**L39 가 여기서 결정적이다** 🟢 — *1 계조 차이가 롤아웃 성공/실패를 뒤집고
닫는 틱을 74→37 로 옮겼다.* 정책은 1 계조에 민감한데, 폐루프는 **10틱 만에**
그 감도 범위를 벗어난다.

## 실제로 무슨 일이 일어나는가 — 그리퍼 명령 실측 🟢

seed 3000, 중앙 구간. 틱별 그리퍼 명령·물체까지 거리·턱 접촉:

| | scripted (성공) | bc (실패) |
| --- | --- | --- |
| 닫기 시작 | 틱 72, 계단식 −0.193→−0.756 | 틱 102, 요동 끝에 −0.7446 |
| 닫을 때 xy | 0.9mm | **2.7mm** |
| 닫을 때 3d | 9.2mm | **9.4mm** |
| 턱 접촉 | 8 | **6** |
| 이후 3d | 9.2 → **13.3** (들어올림) | 9.8 → **9.8** (정지) |
| 종료 | 128틱 성공 | 200틱 소진, 상승 0.00cm |

**bc 의 파지는 scripted 와 사실상 동등하다.** 제대로 접근하고 제대로 닫는다.
그리고 200틱까지 **소수점까지 같은 상태로 멈춰 있다** — 고정점에 빠진다.

seed 3007 도 동일 (틱 96~102 에 xy 4.4mm·접촉 8 로 닫고 이후 정지).

## 한계 — 미리 적어둔다

- **n=1 에피소드**로 얻은 C 절 곡선이다. 다른 에피소드에서 같은 지수가 나오는지 미확인
- 그리퍼 궤적 실측은 **seed 2개**다
- 증강이 성공률을 떨어뜨릴 수 있다(학습이 어려워지므로). 그때도 C 절 지표가 좋아졌으면
  방향은 맞고 강도만 조정한다 — **성공률만 보고 폐기하지 않는다**
- 이 진단은 전부 시뮬이다. 실물에서 같은 지수인지는 알 수 없다
