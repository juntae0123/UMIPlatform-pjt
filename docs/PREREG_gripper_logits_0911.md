## 질문

**같은 데이터·같은 설정으로 학습한 seed0 이 왜 6/100 이고 seed1 은 69/100 인가.**

실측 🟢: 롤아웃 6 / 69 / 25 · 미폐쇄 67 / 20 / 40 · `val_loss` 0.893 / 0.313 / 0.603.
**롤아웃 이전에 학습에서 이미 갈렸다.** 폭 63%p 는 정밀도 문제가 아니라 학습 불안정이다
(그래서 5-run 확장은 답이 아니다).

`joint_delta_gripper_binary` 에서 그리퍼 채널은 **로짓**이고 `to_action` 이 부호만
남긴다. 지금은 그 크기를 아무도 안 본다. 미폐쇄 67/100 이 **두 가지 중 무엇인지
구분되지 않는다** — 처방이 서로 다르다.

| 모양 | 뜻 | 처방 |
|---|---|---|
| **눌림** — p 가 내내 0.5 아래 | 다수 클래스 붕괴가 BCE 에서도 재발 | 임계값·`pos_weight` (사전등록 후) |
| **요동** — p 가 0.5 를 넘나들되 유지 안 됨 | 관측이 닫는 순간을 분해하지 못한다 | 시간 문맥(프레임 스택)·카메라 배치 |

## 조건

- 체크포인트: dagger binary seed0/1/2 · 비교군 scripted 없음(로짓이 없다)
- n=100 · seeds 3000~3099 · render · policy-device cpu · jitter ±50mm · `max_ticks=200`
- **최초 성공 시 종료하지 않는다.** 성공 후에도 p 궤적을 끝까지 본다 —
  폐쇄 유지 여부가 진단 대상이기 때문이다. 따라서 여기 성공률은
  기존 6/69/25 와 **직접 비교하지 않는다** (조기종료 조건이 다르다)
- `--threshold-sweep`: 임계값 {0.3, 0.4, 0.5, 0.6, 0.7} 로 재롤아웃 (조기종료 켬).
  0.5 는 현행과 같아야 하므로 **그 자체가 계측기 검증**이다

## 반드시 출력할 값

1. 에피소드별 `p_max`, `p` 가 0.5 를 넘은 프레임 수, 첫 유지 통과 틱
2. **미폐쇄 에피소드의 `p_max` 분포** (p50/p90/max) ← 눌림/요동을 가르는 값
3. 폐쇄 에피소드의 첫 통과 틱 vs 최근접 틱 (타이밍 오차)
4. p 의 전체 분포 (성공/실패별)
5. 임계값 스윕 성공률 곡선 (옵션)
6. config·URDF·code SHA · EXP_LOG append

## 사전등록 판정 (결과 전 확정)

**주 판정: 미폐쇄 에피소드의 `p_max` 중앙값**

| `p_max` 중앙값 | 판정 | 다음 |
|---|---|---|
| < 0.35 | **눌림** — 확률이 아예 안 올라간다 | 임계값/`pos_weight` 를 사전등록하고 재학습 |
| 0.35~0.5 | **경계 눌림** — 올라가다 만다 | 임계값 하향이 싸게 먹힌다. 스윕으로 확인 |
| > 0.5 | **요동** — 넘었는데 유지가 안 된다 | 관측 문제. 시간 문맥·카메라로 간다 |

**보조 판정**

1. seed0 의 `p_max` 중앙값이 seed1 보다 **0.15 이상 낮으면** → 학습 실행 간 차이가
   그리퍼 헤드에서 났다. 팔이 아니다
2. 임계값 0.3 에서 seed0 성공률이 **+15%p 이상** 오르면 → 눌림 확정, 처방은 임계값
3. 어느 임계값에서도 +5%p 미만이면 → 임계값이 아니다. 확률의 **시점**이 틀린 것
4. 폐쇄 에피소드의 첫 통과 틱이 최근접 틱보다 **+10틱 이상 늦으면** → 시점 지연.
   `probe_exec_envelope` 의 패스 C 가 +3~14%p 였으므로 상한은 작다
5. 임계값 0.5 스윕 결과가 기존 롤아웃과 다르면 → **계측기 오류.** 해석 중단

## 예측 (실행 전) 🟡

- seed0 미폐쇄 `p_max` 중앙값 **0.2~0.4** → 눌림 쪽
- seed1 은 미폐쇄가 20/100 뿐이고 그 에피소드들의 `p_max` 는 0.5 근처
- seed0 이 seed1 보다 `p_max` 중앙값이 **0.2 이상 낮다**
- 임계값 0.3 에서 seed0 **+10~25%p**, seed1 은 **거의 변화 없거나 하락**
  (일찍 닫아 물체를 밀어낸다)
- 폐쇄 시점은 최근접 대비 **−5~+10틱** — 패스 C 상한이 작았으므로 크게 틀리지 않았다

**크게 빗나갈 때**: seed0 `p_max` 가 0.5 를 넘는데도 미폐쇄면 "눌림" 가설이 틀린 것이고,
`closing_moment` 의 **유지** 조건(스치고 복귀)이 원인이다 → 출력 평활화로 간다
