## D-AI-35 — `action` 을 **도달값 `q[t+1]`** 으로 못박는다

**문제.** 같은 `contract_version` 에서 `action` 의 의미가 두 갈래다 (L69).

| 트랙 | `action` | RMS |
|---|---|---|
| 시뮬·정책 | MuJoCo `ctrl` (액추에이터 목표) | 4.6987e-02 |
| UMI 변환기 (나) | `q[t+1]` (다음 스텝 도달 관절각) | 1.602e-02 |
| | | **2.93배** |

**결정 (제안).** 계약의 `action` 을 **"다음 스텝에 도달할 관절각"** 으로 정의한다.
문구를 `contract/episode.py` docstring 에 넣고, 시뮬 수집기는 `ctrl` 대신
다음 틱의 `qpos` 를 기록한다.

**근거 1 — 실물 API 가 도달값을 받는다** 🔵.
waypoint 가 `(positions_rad, gap_m, time_s)` 이고 의미는 "이 시각에 이 자세에
있어라"다. `tracking_rad 0.08` 이 감시하는 것도 도달값이다.
`ctrl` 은 MuJoCo 액추에이터 개념이라 실물 버스에 **대응물이 없다** —
sim2real 지점에서 번역이 한 번 더 필요해진다.

**근거 2 — 재수집이 어차피 온다** 🟢.
시뮬·정책의 처방(`approach_s 1.2 → 3.1s`, 실물 속도 한계 준수)이 98편을
무효화한다. 라벨 의미 통일을 그 한 번의 재수집에 실어 보내면 **추가 비용이 0** 이다.

**근거로 쓰지 않은 것.** "잔차가 작아서 좋다"는 근거가 아니다.
`q[t+1]` 의 RMS 가 1/3 인 것은 학습이 쉽다는 뜻이 아니라 **표현이 다르다**는
뜻일 뿐이고, 절대 표현이 정밀도를 숨기는 문제는 양쪽 다 갖는다.

**확인 필요 (시뮬·정책).** 98편에 `qpos` 가 남아 있으면 재수집 없이 라벨만
다시 만들 수 있다. 남아 있는가.

**되돌릴 조건.**
1. **실험 #1 (98편 A/B, `ctrl` vs `q[t+1]`)에서 `ctrl` 이 게이트 위로 유의하게
   높으면.** 예측은 **게이트에서 구분 불가**로 미리 박아뒀다. 구분 불가로 나오면
   근거 1(실물 API 대응)이 유일한 판단 근거가 되고 그건 계측이 아니라 설계
   판단이다 🟡 — 그것도 그대로 남긴다
2. 실물 API 가 방안 (a)(궤적 profile 수신)로 가면서 인터페이스가 **속도·토크
   지령**으로 바뀌면. 그때는 도달값도 `ctrl` 도 둘 다 맞지 않는다

**상대 트랙 영향.** 있다 — 시뮬 수집기(`data/collect.py`)를 고쳐야 하고 그 파일은
시뮬·정책 소유다. **양 트랙 합의 필요.** 내가 고치지 않았다.

## D-AI-36 — 리샘플러를 **HW/MW 회신 전에 확정하지 않는다**

**결정 (제안).** 30Hz 계약 → 실물 waypoint 열 변환기(리샘플러)의 목표 주기·
보간 방식을 지금 정하지 않는다. 대신 **예산 계측기만 먼저 만들어 둔다**
(`tools/umi_rate_budget.py`, `MEASURE_umi_realapi_rate_0909`).

**근거.** 실물 API 의 가속 검사가 연속 궤적을 구조적으로 거부한다 (L67).
`5.774*v/dt` 는 `dt` 가 작아질수록 커지므로 **주기를 낮추는 방향으로는 못 넘는다**.
속도한계를 딱 지킨 시연도 `dt >= 1.026s` 를 요구한다.
해법 후보 셋 중 둘(실행측 profile 수신 / 검사식 수정)은 **우리 결정이 아니고**,
그 둘 중 하나가 되면 리샘플러는 필요 없거나 완전히 다른 모양이 된다.
지금 만들면 버릴 확률이 높다.

**계측 먼저 원칙 적용.** 대책(리샘플러)보다 계측기(예산 계산기)를 먼저 뒀다.

**되돌릴 조건.** HW/MW 가 (c)(waypoint 희소화)로 답하면 즉시 착수한다.
그때 목표는 **1Hz 급**이고, 정책 출력 30개 중 1개만 남기는 것이 아니라
**구간을 어떻게 요약할지**가 설계 문제가 된다 (평균? 끝점? 곡선 적합?).
그 선택이 성공률에 미치는 영향은 미계측이다.

**상대 트랙 영향.** 없다 — 변환기는 `umi/` 와 `tools/` 안이다.
단 그리퍼 램프(`close_s`)는 시뮬 수집 파라미터라 시뮬·정책 소유다.
