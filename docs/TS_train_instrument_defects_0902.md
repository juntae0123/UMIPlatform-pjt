## 1. 손실에 기준선이 없었다

**증상** 학습 로그가 `train 0.00570` 만 출력했다. 이 값이 좋은지 나쁜지 판단할
근거가 화면에 없었다.

**어떻게 드러났나** 1편 과적합 검사를 하다가 우연히 드러났다. 141샘플을 1.3M
파라미터로 200 epoch 돌렸는데 `0.00570` 에서 평평해졌다. 완전히 외워야 정상인
상황이라 이상하다고 느꼈고, 그제서야 **"델타 0 을 출력하는 예측기"의 손실을 따로
계산**해봤다 — `0.0075` 였다.

```
자명한 예측기(항상 0)  0.0075
200 epoch 후 train     0.0057   ← 24% 나은 게 전부였다
```

**왜 위험한가** `0.00570` 은 작아 보인다. 며칠 동안 이 수치를 "학습은 되고 있다"의
근거로 읽고 있었다. 기준선이 옆에 있었다면 첫날에 잡혔다.

**조치** 학습 시작 시 자명한 예측기의 손실을 같은 단위로 출력한다.

```
⚠️ 자명한 예측기(항상 0) 손실 = 0.76090
   epoch 손실이 이 값 근처에서 멈추면 학습이 안 되고 있는 것이다.
```

**일반화** 이 프로젝트는 `diagnose_bc.py` 로 정책의 손실을 identity·mean 예측기와
비교하는 도구를 이미 갖고 있었다. **그 원리를 학습 스크립트 자신에는 적용하지
않았다.** 계측기를 만들면서 자기 자신은 계측하지 않은 것이다.

## 2. 회귀 목표가 두 자릿수 작았다

**증상** 1편 141샘플조차 외우지 못했다. 위 1번의 `0.0057` 이 그것이다.

**원인** 계약은 관절 **범위** 기준으로 [-1,1] 정규화한다. 그런데 델타
(`action - state`)는 그 범위의 **0.0008 ~ 0.03** 밖에 안 된다.

```
관절별 델타 표준편차 (실측)
  shoulder_pan   0.00070      wrist_flex   0.00994
  shoulder_lift  0.00219      wrist_roll   0.00004
  elbow_flex     0.00350      gripper      0.11480
```

마지막 선형층은 O(0.1) 규모 출력으로 초기화된다. 목표가 O(0.001) 이면 학습
대부분이 "일단 0 쪽으로 줄이기"에 쓰이고 정작 중요한 구조는 학습되지 않는다.

**조치** 데이터셋 통계로 관절별 zero-mean unit-std 표준화. 통계는 체크포인트에
함께 저장한다 — 없으면 원 출력을 행동으로 되돌릴 수 없다.

**결과** 🟢

```
              표준화 전    표준화 후
train / 기준선   76%         0.7%
```

**신경망은 처음부터 학습할 수 있었다.** 목표 스케일이 막고 있었을 뿐이다.

⚠️ 이 문제는 절대 목표(`joint_absolute`)에서는 드러나지 않았다. 절대 관절각은
O(0.1~1) 이라 스케일이 맞았기 때문이다. 대신 거기서는 **상태가 정답의 86% 를
설명하는 지름길** 문제가 있었다. 두 표현이 서로 다른 이유로 실패했고, 하나를
고치면 다른 문제가 드러나는 구조였다.

## 3. `best val_loss` 가 체크포인트를 고르고 있었다

**증상** 200 epoch 학습의 체크포인트 메타가 `epochs 1` 이었다.

**원인** `save_best_on: val_loss`. val 곡선이 평평하면 **임의의 이른 epoch** 이
최저값이 된다. 1편 과적합 검사에서는 epoch 1 의 `0.73303` 이 200 epoch 내내
갱신되지 않았다.

**왜 위험한가** 그 체크포인트로 롤아웃을 돌려 `bc 0/5 = 0.0%` 를 기록했다.
**학습되지 않은 신경망을 평가한 것이다.** 그대로 "정책이 0% 다"로 문서에 들어갈
뻔했다.

**이 프로젝트에서 특히 나쁜 이유** 절대원칙과 정면으로 충돌한다. 이 저장소는
`README`·`configs`·`eval/rollout.py` 세 곳에 "val loss 는 학습이 망가졌는지
확인용이고 판정은 롤아웃 성공률이 한다"고 적어뒀다. **그래놓고 정책 선택을 val loss
가 하고 있었다.** 규칙을 문서에만 적고 코드에는 적용하지 않은 것이다.

**조치** 주 체크포인트를 **마지막 epoch** 으로. best-val 은 `<이름>_bestval.pt` 로
따로 저장하고 참고용으로만 둔다.

## 4. 학습 패스가 표준화를 통째로 빠뜨리고 있었다 (2번 수정이 만든 결함)

**증상** 1편 과적합 검사. train 손실은 0.00563 까지 내려갔는데 `--from-episode` 로
물체를 기록 위치에 고정해도 롤아웃 0%, 상승 0.00cm.

**어떻게 좁혔나** 0% 의 후보 원인을 셋으로 쪼개는 계측기(`eval/trace_execution.py`)를
먼저 만들었다. A 기록 행동 재생 / B 기록 관측→예측 대조(교사강요) / C 폐루프 관측 추적.

```
A  기록 행동을 그대로 되먹임        성공 · 5.139cm · state 편차 0.000203  → 실행 경로 정상
B  기록 관측 → 예측 vs 기록 행동     오차÷델타 = 1.0309                   → 자명한 예측기 수준
C  폐루프 t=0                       state차 0.0 · image차 0.0 · action차 0.62
```

C 의 t=0 이 결정적이었다. **입력이 기록과 한 비트도 다르지 않은데 출력이 틀렸다.**
관측 파이프라인도 실행 경로도 아니고 네트워크만 남았다. `run_epoch` 을 다시 읽었다:

```python
tr = run_epoch(model, loaders["train"], criterion, device, optimizer, float(t["grad_clip"]))
va = run_epoch(model, loaders["val"], criterion, device, target_mean=t_mean, target_std=t_std)
```

학습 호출이 `target_mean/target_std` 를 빼먹었다. `optimizer`·`grad_clip` 을 위치 인자로
넘기다 선택 키워드 둘이 뒤에 남았다. 학습은 raw 델타를 회귀하고, 추론은
`raw × std + mean` 으로 역표준화한다. std 가 0.0007~0.1148 이니 델타가 한 번 더 곱해져
사라진다. 팔이 안 움직인다.

**부작용 — 어시스턴트의 판정 오류** "train 0.00563 = baseline 0.76090 의 0.7%, 외웠다"는
**raw 단위를 표준화 단위로 나눈 것**이었다. 진짜 신호는 val 0.73198 대 자명한 예측기
0.76090 — 외운 적이 없었다. 손실에 단위 표기가 없어서 두 수를 비교할 수 있는 것처럼 보였다.

**조치** 선택 키워드 둘 → 필수 위치 인자 `TargetTransform` 하나. baseline 도 같은 객체를
통과시켜 손실과 기준이 다른 단위가 될 수 없게 했다. 시작 시 `손실 단위:` 를 출력한다.
커밋 `6f7e704`.

**일반화** 2번 결함을 고치면서 만든 결함이다. 선택 인자로 넣은 변환은 빠져도 아무 곳에서
예외가 나지 않는다. **손실의 의미를 바꾸는 변환은 선택이면 안 된다.**

## 5. 그리퍼 델타는 141스텝 중 124스텝에서 정확히 0 이다

**증상** 4번을 고친 뒤 1편 재검사. 팔 관절 5개는 오차÷이동량 0.14~0.20 으로 내려갔는데
그리퍼만 1.07 — 전혀 배우지 못했다. 폐루프에서 그리퍼가 열리지도 닫히지도 않았다.

**어떻게 좁혔나** trace_execution 에 관절별 비율을 추가해 어느 관절이 미달인지 보이게
했다. 그리퍼 하나였다. 에피소드의 그리퍼 열을 그대로 찍어봤다:

```
t=0~6   열기 (delta +0.625 → 0)      7스텝
t=7~63  0                            57스텝
t=64~70 닫기 (delta −0.39 → 0)       7스텝
t=71~140 0 (닫힘 명령 = 닫힌 상태)   70스텝
```

그리퍼 명령은 에피소드당 두 번만 바뀌는 **설정값**이다. 델타로 표현하면 88% 가 정확히
0 인 스파이크 신호가 된다. L1 손실에서 대부분 0 인 목표의 최적 상수는 중앙값 = 0 이고,
신경망은 정확히 그것을 배웠다.

**조치** 팔 관절은 델타, 그리퍼만 절대 명령 (`joint_delta_gripper_abs`). 그리퍼 인덱스는
`configs/so101.yaml` 에서 읽는다. 왕복 변환 오차 0 확인. → D-AI-28. 커밋 `acdf751`.

**검증** 이 세션의 클라우드 CPU 에서 같은 seed 0 에피소드로 end-to-end 재실행:
A 통과 · B 0.51 (관절별 0.28/0.20/0.20/0.25/0.24/0.65, 150 epoch 미수렴) · C t=0 일치 ·
**폐루프 성공, 상승 5.037cm**. 이 프로젝트의 첫 폐루프 성공이다 (n=1, 기록 조건 고정, 시뮬).
