## 무엇을 재는가

지금까지의 관통 계측은 입력이 **전부 도달 가능**했다(유효 관절 배치의 FK).
사람 손 pose 는 그렇지 않다. 실측된 자유도 배분(`MEASURE_umi_roundtrip_0907` M5):

```
pan lift elbow_flex wrist_flex (4개)  →  위치 3 + 접근축 2 = 5구속  (과결정)
wrist_roll (1개)                      →  roll 전담, 완전 독립
```

**roll 은 이 실험의 대상이 아니다.** 결합이 0 이라 늘 맞춰진다.
무너지는 것은 (위치, 접근축) 조합이다. 도달 가능한 pose 를 두 방향으로 밀었다 —
위치를 무작위 방향으로 d mm, 또는 EEF 프레임 전체를 접근축에 수직인 무작위 축
둘레로 α 도 기울임(손목이 실제로 하는 일).

## R2. 위치[mm] 와 축[도] 가 거의 1:1 로 함께 움직인다 🟢

모든 행에서 위치 오차[mm] ≈ 축 오차[도] 다 (0.113/0.108 · 1.244/1.148 · 3.278/2.999
· 7.135/7.125 · 14.996/14.346). 최소자승이 `[e_pos ; 0.15·e_axis]` 를 줄이므로
두 오차의 비율은 `axis_weight` 가 정한다.

**결과적으로 예산 5mm 와 5도가 거의 동등하게 구속한다.** 그래서 "무엇이 먼저
무너지나"에 깔끔한 답이 없다 — 둘이 같이 무너진다.

이건 지렛대다. `axis_weight` 를 올리면 위치 오차를 내주고 축 정확도를 산다.
지금은 어느 쪽도 유리하다고 볼 근거가 없어 기본값을 건드리지 않았다
(그 파일은 시뮬·정책 소유이기도 하다).

## R3. 자세 기울기가 위치 지터보다 압도적으로 비싸다 🟢

```
위치 50mm  →  수용률 63.5%
자세 10도  →  수용률 20.5%
```

기전은 **관절 한계**다. 한계 클램프가 자세 섭동에서 0 → 53 → 62 로 급증한다
(위치 섭동에서는 50mm 에서도 8건). 같은 위치에서 팔을 기울이려면 손목이 범위를
넘어가야 한다.

## R4. 수집 프로토콜에 바로 걸린다

| | 실측 허용폭 (수용률 90% 이상) |
|---|---|
| 접근 방향 | **약 5도** |
| 위치 | **약 20mm** |

**시연자의 접근 방향이 위치보다 훨씬 중요하다.** 기존 규칙 "환경은 다양하게,
시연 방식은 동일하게"에 숫자가 붙는다 — 일정해야 하는 것은 주로 **각도**다.

⚠️ 위치 20mm 는 IK 기준이다. 재생 위치 허용오차는 ±10mm 에서 3/4 🟢 이므로
   **위치 예산을 지배하는 것은 IK 가 아니라 재생이다.** 두 값을 혼동하면 안 된다.

## R5. 정정 — "다양체 밖에서 다중시작이 8배" 는 틀렸다

첫 스윕이 170초 타임아웃을 냈고, 원인을 "다양체 밖에서는 수렴이 없어 모든 스텝이
시드 없는 스텝이 되고 다중시작 8회를 돈다"로 **추론**해서 보고했다. 재보니 틀렸다.

```
다중시작 켬/끔 실측 (tilt 20도, 100스텝)   6.13초 vs 6.00초  →  1.02배
옛 시드 규칙까지 함께 켬                    7.95초            →  1.33배
```

**8배가 아니라 1.33배다.** 다중시작은 첫 성공 이후에는 발동하지 않는다
(`q_prev` 가 한 번 설정되면 유지된다).

타임아웃의 실제 원인은 `max_iters` 다. 500 → 120 (4.2배)과 스텝 수 1.5배로
6.25배가 설명되고, 88초 × 6.25 ≈ 550초다. **다양체 밖 목표는 조기 종료가 없어
반복 한도를 전부 돈다** — 그게 원인이다.

## R6. 시드 규칙 — 바꿨다가 되돌렸다 🟢 (n=300/조건, 6편 × 50스텝)

R5 의 거짓 근거로 `convert()` 의 시드 규칙을 "채택된 스텝만" → "무조건 이어감"으로
바꿨다. 재보니 정확도를 잃는다.

| tilt 20도 | 채택된 스텝만 (원래·복원) | 무조건 이어감 (되돌림) | 판정 |
|---|---|---|---|
| 관절 한계 클램프 | 44/300 (14.7%) | **114/300 (38.0%)** | 차이 23.3%p = **6.7 SE, 유의** |
| 위치 오차 p95 | 28.40mm | **85.25mm** | 3배 악화 |
| 위치 오차 중앙 | 13.01mm | 16.76mm | — |
| 수용률 | 11.7% | 7.7% | 차이 1.66 SE, **유의하지 않다. 인용 금지** |
| 경과 | 68.20초 | 61.07초 | 1.12배 |

**실패한 자세를 시드로 쓰면 궤적이 관절 한계 쪽으로 끌려간다.** 비용 1.12배로
정확도를 사는 게 맞다. 원래 규칙으로 복원했다.

위치 섭동(20mm·50mm)에서는 두 규칙의 차이가 없었다. 차이는 가장 다양체 밖인
조건에만 나타난다.

## 미검증

| 항목 | 상태 |
|---|---|
| `max_iters=500` 에서의 재현 | **미대조** 🟡. 다양체 밖 잔여 오차가 바뀔 수 있다 |
| 실제 사람 손 궤적 | **해당 없음.** 이건 도달 가능 pose 의 섭동이다. 민감도 순서(자세 ≫ 위치)는 이어질 것으로 보지만 근거는 없다 |
| `axis_weight` 를 올렸을 때 | 미측정. 지렛대라는 것만 확인 |
| 수용률의 절대값 | 섭동 크기 분포에 전적으로 의존한다. **곡선으로만 인용한다** |
